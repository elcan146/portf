CEKIGREP

NATIONAL SPECTRUM OVERSIGHT

A specialized SIGINT and spectrum monitoring platform engineered to track, analyze, and secure the national radio frequency landscape.

THE HARDWARE PIPELINE

Ingesting raw spectrum data via RTL-SDR, HTOOL SDR 6, NRSP-ST, and SDRuno receivers. A custom digital signal processing engine executes precise FFTs to instantly detect jamming, interference, and cross-border anomalies.

THE DATA ARCHITECTURE

Built for zero-latency telemetry. Tens of millions of historical sweep records are aggressively optimized through in-memory ring buffers and recursive PostgreSQL queries, streaming live spectrum arrays at 4Hz over WebSockets.

THE TACTICAL INTERFACE

A real-time 3D React command center powered by WebGL shaders and live data waterfalls. Protected by a zero-trust FIDO2 WebAuthn security model and featuring an embedded AI assistant for natural-language database querying.

THE DEPLOYMENT

Operating across seven regional nodes. Monitoring over 400 frequency-transmitter mappings to ensure broadcast integrity, automate outage alerting, and classify RF intent across the digital frontier.

THE ARCHITECTURE

Powered by a custom, framework-agnostic TypeScript engine. Core state transitions operate entirely decoupled from the UI using a draft-mutation pattern, allowing the exact same deterministic game logic to drive both a React web client and a native Expo application.

THE ENGINE

A specialized effects layer resolves complex card abilities, resurrection hooks, and 30 unique location modifiers. The engine operates purely headlessly, communicating with the render layer strictly through transient event queues while a probability-driven AI evaluates optimal plays.

THE CONTENT PIPELINE

Engineered a custom data pipeline to manage scale. Node and Python code generators parse plain-text design documents, compiling 214 unique cards, 8 factions, and extensive lore directly into strictly typed code—ensuring a single source of truth.

THE PRESENTATION

Rendered through a bespoke gothic-CRT aesthetic. Phaser 4 orchestrates animated board states bridged seamlessly to a React DOM, backed by a dual-mode low-latency audio architecture and an integrated original soundtrack player.
